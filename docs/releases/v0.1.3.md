## v0.1.3

Factory Droid 插件为 CPA Manager Plus 原生凭证页面补齐刷新额度功能，无需单独部署管理页面。

### 🛠️ 变更

- 打开一次 Factory Droid 插件页并连接后，自动激活原生凭证卡片、列表和详情抽屉的额度增强；离开插件页仍然有效。
- 展示官方标准 5 小时、7 天和月额度、剩余比例及重置时间；请求数、Token 和费用继续使用 CPA / Manager 统计。
- 额度缓存按凭证隔离；重复打开不重复注入；退出登录或切换连接清除缓存；限制并发并支持失败重试。
- 修复反代只附加 `Connection: upgrade` 时误拒绝普通 JSON / SSE 请求的问题；真实 `Upgrade` 请求仍被拒绝，升级头不向 Factory 透传。
- 前端增强脚本和样式内嵌四平台动态库；构建门禁检查资源可访问性和前端语法，宿主回归固定为 CPA v8.0.52。

### 📦 使用

更新插件后打开 CPA Manager Plus 的 Factory Droid 页面，看到“原生额度已启用”后返回凭证管理。整页刷新、退出登录或切换连接后需重新进入插件页激活。同源且未限制父页面访问的 iframe 才能启用增强；当前适配 Manager v1.14.10。

本版本不修改 `management.html`，不需要 JS Handler，不新增独立价格、账本或窗口统计系统。上游未提供的窗口和数值保持缺省。

### 🧪 验证边界

发布构建执行 Rust 测试、安装包及校验和检查，并通过真实 CPA v8.0.52 连接本机模拟上游回归 OAuth、模型、JSON/SSE、会话隔离和反代协议头。真实账号 OAuth 登录和付费推理不属于本次验证范围。

本地已通过 16 项 Rust 测试、71 项 CPA 宿主检查和 8 项额度解析边界检查。使用 CPA v8.0.52、Manager v1.14.10 官方原版页面及现有真实凭证，验证了标准额度读取、卡片与列表、详情抽屉、遮罩关闭和切页持久性；注入模拟错误及迟到响应，验证失败保留、重复激活和退出登录清理。真实额度查询曾出现出站连接失败，重试后恢复，页面会如实保留失败状态。
