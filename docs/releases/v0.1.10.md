## v0.1.10

Factory 凭证卡片增加套餐标签；同一用户在同一组织重新 OAuth 授权时更新已有凭证，避免重复添加账号。

### 🧩 套餐标签

- 在 CPA Manager Plus 卡片的“优先级”左侧显示蓝色套餐标签，与其他提供商的展示位置一致。
- 套餐随额度刷新。优先读取额度接口的 `planType`，缺少时读取官方账单页使用的账号套餐字段；`pro_plus` 显示为 `Plus`。
- 套餐查询失败、无权限或未返回名称时隐藏标签，额度仍正常展示。凭证组织与套餐组织不一致时不显示套餐。
- 套餐沿用额度查询的凭证隔离、3 分钟刷新间隔和当前标签页快照；Manager 出现原生套餐标签时不重复插入。

### 🔄 OAuth 重新授权

- 同一 Factory 用户、同一组织重新授权时更新已有 OAuth 凭证的令牌，保留账号 ID、文件名、名称、启停状态、优先级、备注和 CPA 原生模型规则。
- 新账号使用可信用户 ID 和组织 ID 生成稳定文件名；并发首次授权落到同一凭证。已删除账号重新授权时使用新标识，避免恢复历史删除记录。
- API Key、其他用户和其他组织的凭证分别保存，不按邮箱合并。
- 兼容旧版随机文件名；已有多个重复凭证时固定选择一条更新，不自动删除其余凭证。缺少可信身份或凭据列表不可用时不另建账号。

### 📦 升级

更新插件并确认 CPA 已重新加载；刷新 Manager 页面，未启用自动加载时先进入 Factory Droid 页面激活增强。套餐会在下一次额度查询后显示，也可手动刷新额度。

已有 OAuth 凭证无需迁移。再次授权会复用符合用户和组织身份的现有凭证；历史重复项仍由管理员自行处理。

### 🧪 验证与边界

- 本地运行 Rust 测试、前端语法检查、版本与注册表一致性检查，以及真实 CPA v8.0.52 宿主的模拟上游回归。
- 套餐卡片通过浏览器验证，覆盖位置与样式、凭证隔离、手动刷新、整页重载恢复、缺失套餐、优先级编辑和原生标签兼容。
- OAuth 回归覆盖重复授权、旧文件名、配置保留、用户与组织隔离、并发授权、删除后重新授权及缺失身份。
- 集成回归使用本机模拟上游；实际套餐可读性取决于 Factory 接口及当前凭证权限。四平台安装包由发布流水线完成构建和宿主检查后公开。

升级前按 README 备份 CPA 的 `auth-dir`、插件 `data-dir` 和动态库；需要回退时恢复备份及 v0.1.9 动态库。
