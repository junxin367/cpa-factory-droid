## v0.1.6

修复 v0.1.5 在手动退出登录、切换到登录页时可能跳过短期额度快照清理的问题。

### 🛠️ 变更

- 路由变化时立即检查授权，退出登录即清理当前管理连接的快照并中止请求，不再依赖后续 401 事件或停留在凭证页面。
- 保留 v0.1.5 的进入页面刷新规则：不足 3 分钟跳过，停留页面不轮询，手动刷新立即执行。
- 重置时间仍在卡片用量行右侧显示“n 小时 / 天后”，悬停显示完整日期时间。预测算法不变。

### 🧪 验证

手动退出场景先在旧实现复现，再验证修复后立即清理，未触发任何 401 事件。沿用已通过的进入页面、3 分钟冷却、整页重载、手动刷新和相对时间检查。发布门禁包含 16 项 Rust 测试、79 项 CPA v8.0.52 宿主检查和四平台打包。

本地 CPA v8.0.52 + Manager v1.14.10 预加载同一增强模块验证：首次进入后返回页面及整页重载没有增加额度请求，手动刷新新增一次查询；“2 小时后 / 6 天后 / 29 天后”位于用量行右侧，悬停属性提供完整日期时间。测试结束已恢复本地 Manager 页面，未修改线上管理页。

### 📦 升级

建议直接更新到 v0.1.6 并刷新 Manager 页面。已启用的自动加载开关继续有效，无需重新配置；未启用时仍先进入 Factory 页激活。
