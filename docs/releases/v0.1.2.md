## v0.1.2

修复 Factory Droid 已安装、已启用，但在 CPA v8.0.47 中显示“未注册”且没有菜单入口的问题。

### 🛠️ 修复

- 注册时声明插件实际使用的最低 RPC Schema 7，兼容最高支持 Schema 8 的 CPA v8.0.47，同时保留 v8.0.52 支持。
- 不再无条件要求 Schema 10；当前插件只提供一个 Factory 身份入口与模型目录，无需多提供商协议扩展。
- 对显式声明过低或无效协议版本的宿主返回清晰错误，并在初始化状态前完成校验。
- 发布门禁新增实际宿主版本、成功注册、菜单、OAuth 与额度能力及页面资源检查，防止“文件已安装”被误认为“插件已生效”。

### 🧪 验证

Windows x64、Linux x64、macOS Intel 和 Apple Silicon 均分别使用固定 CPA v8.0.47、v8.0.52 验证；每个宿主执行 38 项检查，包括注册、三类原生 JSON/SSE、会话缓存隔离、模型规则、自动目录刷新和模拟 OAuth 续期。另有 16 项 Rust 单元测试及更新清单检查。

测试仅连接本机模拟上游，不代表真实 Factory 账号的完整 OAuth 登录和推理权限已经验收。

### 📦 升级

在插件商店更新 Factory Droid 到 v0.1.2 即可，无需为此升级 CPA 内核。手动安装时选择对应系统和架构的 ZIP；更新前保留旧动态库和插件数据目录备份，保留 `wire_namespace`。

四平台安装包、ZIP 校验和、包内动态库校验和及 `latest.json` 随本版本发布。RPC Schema 7 表示协议能力需求，已执行的宿主兼容性验收范围为 v8.0.47 和 v8.0.52。
