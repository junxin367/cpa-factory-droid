## v0.1.12

修复 Anthropic 大会话中历史截图持续累积、在模型上下文用满前触发 Factory 上游 HTTP 413 的问题。

### 🛠️ 请求体大小与旧图片

- 按最终发送的紧凑 UTF-8 JSON 字节数检查请求，超过 4,000,000 字节时，从最旧的历史图片开始替换为明确的文字省略说明。
- 保留最近一条含图片的用户/工具结果消息中的全部图片，支持多图对比；保留工具调用与结果配对、结果文本、缓存标记和思考签名。
- 只调整本次发送副本，客户端保存的会话与图片不变。模型在当前请求中无法查看已省略的旧图片，需要时可重新附图。
- 图片缩减目标不作为纯文本硬上限；最新图片、文档或文本仍过大时，由上游返回实际错误。

### 🔄 HTTP 413 恢复

- 上游返回 HTTP 413 且仍有旧图可缩减时，再缩减一次并仅重试一次；没有体积下降时不重发。
- JSON 与 SSE 使用相同规则；重试前关闭失败流，在同一宿主调用上下文下新建 HTTP 操作，保留会话及消息标识，继续响应客户端取消。
- 最终失败保留 HTTP 413 和上游原始原因，追加压缩会话、减少附件或携摘要新建会话的提示。
- 其他 HTTP 错误、Responses 和 Chat Completions 请求保持原有行为。

### 🧪 验证

- Rust 回归覆盖 UTF-8 字节边界、最旧图片优先、多图保留、嵌套工具结果、思考签名和最终错误诊断。
- 真实 CPA v8.0.52 宿主配合本机模拟上游，覆盖预先缩减、413 单次重试、持续 413、不可缩减内容、JSON/SSE 和操作释放。
- 完善跨平台取消测试：先中断 socket，再等待读取线程退出，最后关闭 HTTPConnection，避免测试脚本自身并发关闭响应对象。
- 原失败请求只回放至本机模拟上游，缩减后约 3.88 MB；此回放验证体积和协议处理，不替代真实 Factory 模型对缩减后视觉内容的验收。
- 四平台安装包由发布流水线完成构建和真实 CPA 宿主检查后公开。

### 📦 升级与回退

在 CPA 插件管理中更新 Factory Droid 并确认插件完成重载，无需修改模型或账号配置。

升级前按 README 备份插件目录及数据；需要回退时恢复上一公开版本 v0.1.10 动态库。此版本不迁移凭据或持久化状态。
