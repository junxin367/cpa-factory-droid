## v0.1.4

为 Factory 凭证补齐 CPA Manager Plus 卡片和详情抽屉中的窗口用量与容量预测。

### 🛠️ 变更

- 保留真实 Factory 凭证类型，按凭证名称、索引和时间区间调用 Manager 原生窗口统计接口；请求数、Token、费用及成功率均来自 Manager。
- 卡片显示窗口已用费用 / Token 和可用预测；抽屉增加前期、当前已用、当前预测三列。
- 优先使用官方窗口时间；只有重置时间时明确标记推导边界。未实际观测到上一周期时，显示“前一等长区间”。
- 预测遵循 Manager 的当前用量 / 已消耗比例规则；Core 混合用量、标准额度耗尽、空样本、无效边界或过期数据不生成预测。
- 兼容毫秒格式的官方窗口起点；元数据接口校验凭证身份，仅返回脱敏的标准额度窗口。
- 独立加载统计适配模块，继续支持打开一次插件页激活；不替换 `management.html`，不增加单独账本或价格表。
- 新增“自动加载额度增强”：每个浏览器首次启用后，刷新管理页自动加载并复用当前登录授权；可以关闭，不额外保存密钥。仅处理管理页面导航，插件不可用时回退原页面。

### 🧪 验证

16 项 Rust 测试、78 项真实 CPA v8.0.52 宿主检查。纯函数验证覆盖窗口边界、凭证错配、数据缺失、周期切换及预测撤销。Manager v1.14.10 隔离实例验证 7 项聚合和价格行为，同批 Token 更改 Manager 价格后费用从 $4 更新为 $6。

Node 沙箱检查了卡片/抽屉填充渲染、自动加载导航范围、重复注入、404 回退注销、CSP 保留、未记住密钥的授权观察、请求不改写及退出后撤销。

测试请求只写入隔离 Manager，真实账号仅验证额度读取，不执行付费推理或真实 OAuth 登录。

本地浏览器已确认三列窗口区域和空统计展示。后续可视验证被桌面浏览器工具的安全检查终止，因此自动加载在真实浏览器中的注册、刷新恢复，以及填充数据后的完整视觉回归尚未验收；代码级检查不替代该项验收。

### 📦 使用与边界

升级插件后刷新 Manager 页面，首次打开 Factory Droid 并连接，可开启“自动加载额度增强”。开启后后续刷新无需再打开插件。仍需同源且允许访问父页面的插件 iframe；自动加载要求 HTTPS 或本机地址，不覆盖管理页已有的其他 Service Worker。

窗口用量统计的是该凭证在本 CPA 记录的请求，预测是样本估算，不是 Factory 官方账单或总额度金额。窗口没有匹配记录时显示未采集；历史数据不足时不会凭空补齐。旧版 Manager 的内置额度风险筛选和批量刷新流程保持原状。
