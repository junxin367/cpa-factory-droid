## v0.1.7

修复 Claude Code 请求被插件以 `invalid_native_request` / “原生协议请求头无效或包含代理标识”拒绝的问题。本版本正式包含此前仅在本地完成的 Header 修复。

### 🛠️ 变更

- 向上游统一使用已核验的 Factory CLI 1.2.0 请求头基线，停止透传调用者的协议版本、beta 和客户端标识。
- Anthropic 固定使用 `anthropic-version: 2023-06-01`、`anthropic-beta: fine-grained-tool-streaming-2025-05-14`；受信任模型目录要求 fast 模式时追加对应标志。
- OpenAI 原生入口不转发调用者的 `OpenAI-Beta`。Factory 鉴权、会话和跟踪标识仍由插件从凭据及隔离规则生成。
- 移除对调用者 beta 日期格式的错误限制，`claude-code-20250219` 不再触发该项 HTTP 400。
- 保留 v0.1.6 的页面刷新、短期快照清理和相对重置时间行为。

### 🧪 验证

19 项 Rust 测试、85 项 CPA v8.0.52 宿主检查。新增检查在 Anthropic、Responses、Chat Completions 三种协议的 JSON/SSE 请求中注入冲突版本、Claude Code beta 和代理信息，验证调用正常且调用者 Header 不泄漏。

验证仅使用本机模拟上游，不代表真实 Factory 账号的所有实验功能或付费推理已验收。

### 📦 升级

更新插件到 v0.1.7 后，确认 CPA 已重新加载插件；必要时重启 CPA。仅刷新管理页面不会替换内存中正在运行的动态库。

自定义 beta Header 不再直接启用上游实验功能。Factory CLI 的 fallback 标志依赖配套请求流程，本插件未启用该流程，因此不单独照搬这些标志。
