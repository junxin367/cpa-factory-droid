## v0.1.1

Factory Droid 首次正式发布，使用 CPA 原生凭证、模型调度和请求统计。

### 📝 功能与修复

- 支持 Factory API Key 和 CPA 原生 OAuth 设备授权，OAuth 令牌由 CPA 调度续期。
- 自动读取官方 Droid 模型目录，使用唯一的 `factory/<模型>`，不再发布账号 UUID 模型或要求逐个付费验证。
- 插件页面简化为凭证接入；额度提供标准 5 小时、7 天、30 天窗口，费用由 CPA 管理端统一计价。
- 请求包装参考官方 Droid CLI 1.2.0；清理下游鉴权、代理与追踪元数据，独立处理会话、缓存分组和安全标识。
- 修复相同根会话中同名 Codex 子代理忽略线程 ID 的问题，重启后匿名映射保持稳定。
- 补齐 API Key 目录的自动刷新调度，保留 OAuth 的令牌续期策略。
- 修复 CPA 排除、别名和前缀规则导致插件误报目录未同步的问题。
- 提供 CPA-Manager-Plus v1.14.10 通用插件额度适配补丁。

### 📦 安装包

- `factory-droid_0.1.1_windows_amd64.zip`
- `factory-droid_0.1.1_linux_amd64.zip`
- `factory-droid_0.1.1_darwin_amd64.zip`
- `factory-droid_0.1.1_darwin_arm64.zip`

ZIP 内动态库位于根目录。`checksums.txt` 提供 ZIP 的 SHA256，包内 `SHA256SUMS.txt` 校验动态库，`latest.json` 提供 CPA 更新清单。

### 🧪 验证与兼容

四个平台均通过 Rust 测试、打包检查和固定 CPA v8.0.52 的真实宿主集成回归，Linux 另检查 GLIBC 2.35 基线。模拟上游覆盖会话与缓存隔离、16 会话并发、三类原生 JSON/SSE、重启、原生模型规则、API Key 自动刷新和 OAuth 续期。

需要支持 C ABI 1 / RPC schema 10 原生插件的 CPA。Windows 需要 VC++ v14 运行库。目录自动发现需要单独安装官方 Droid CLI；未配置时使用内置目录。

真实账号的 OAuth 完整授权、推理权限与缓存命中率尚未验收。插件不做跨协议转换，不支持 WebSocket；应用层请求包装对齐不代表 TLS 或网络行为与官方 CLI 完全相同。

### 🔄 升级与恢复

升级前备份 CPA 认证目录、插件数据目录和旧动态库。旧 `factory/<账号ID>/<模型>` 应改为 `factory/<模型>`。保留数据目录中的 `wire_namespace`，避免升级或重启改变匿名会话映射；旧账本不会伪造为新的 CPA 用量历史。
