## v0.1.5

取消 Factory 额度定时自动刷新，进入页面时遵守 3 分钟间隔，并将重置时间对齐 Manager 原生卡片。

### 🛠️ 变更

- 取消 15 秒定时检查和停留页面时的额度轮询。进入凭证页或切回提供商筛选时，每个显示中的 Factory 凭证只检查一次，距上次查询尝试不足 180 秒则跳过。
- 手动刷新额度、刷新历史和页面刷新立即执行，不受自动刷新间隔限制。
- 同一标签页整页重载恢复 3 分钟内的额度快照，避免重复请求；缓存按管理授权与凭证隔离，不保存密钥，退出登录或切换连接后清理。
- 卡片重置时间移动到进度条下方、用量行右侧，显示“n 小时 / 天后”；抽屉采用同样的相对时间。悬停显示完整日期和时间。
- 预测算法保持不变；自动加载增强脚本的开关保持不变。

### 🧪 验证

前端模拟时钟、路由和存储检查覆盖进入页面、停留、DOM 变化、3 分钟冷却、手动刷新、整页重载和退出清理。发布门禁执行 16 项 Rust 测试、79 项 CPA v8.0.52 宿主检查及四平台打包。

### 📦 升级

更新插件并刷新 Manager 页面。已启用自动加载的浏览器继续自动加载增强脚本，但不会定时查询额度；未启用时仍先进入 Factory 页激活。
