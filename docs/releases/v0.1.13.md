## v0.1.13

修复 Factory 模型页缺少已禁用模型，以及未配置 Droid CLI 时模型目录长期不更新的问题。

### 🛠️ 完整模型定义

- 向 Manager 提供过滤前的完整模型定义，让原生“已禁用”列表保留被排除的模型、禁用原因和恢复入口。
- 增强模块仅重定向同源 Factory 模型定义查询，保留管理端鉴权；可用路由、禁用规则、别名和前缀继续由 CPA 管理。
- 刷新目录时先完成网络读取，再读取并更新凭据，保留下载期间刚保存的模型规则。

### 🔄 官方目录自动同步

- 未配置 CLI 时，默认从 Factory 官方模型页面同步，不再只更新时间戳并沿用 13 个固定模型。
- 内置 2026-11-11 官方页面的 74 个候选，当前可注册 60 个支持模型；不支持的原生协议、未核实的托管路由和已废弃模型继续过滤。
- 正常目录由 CPA 每 24 小时自动刷新；打开或刷新模型页时按 3 分钟间隔检查共享目录，失败后保留上次目录并安排重试。
- 显式配置 Droid CLI 时仍以 CLI 为准。模型目录同步不执行推理，也不代表账号拥有全部模型权限。
- 旧凭据首次加载时补充公共目录；已使用公共目录的过期凭据继续走宿主刷新流程，避免目录检查推迟身份校验。

### 🧪 验证

- 覆盖禁用模型完整保留、上游新增模型、目录故障与重复 ID 拒绝、自动刷新和并发规则编辑。
- 检查 Factory 元数据查询适配，验证 fetch、Request 和 XHR 保留原管理端鉴权及请求参数。
- 原生别名按保存并重载后的实际发布集合和调用结果验证，避免将宿主文件监听时序当成插件模型注册失败。
- 四平台安装包通过 Rust 测试、打包校验和真实 CPA v8.0.52 宿主集成验证后才公开。

### 📦 升级与回退

在 CPA 插件管理中更新 Factory Droid，并重启或重载插件。更新后刷新 Manager 页面，打开一次 Factory 插件页加载增强；已开启自动加载时会随管理页加载。

升级前备份插件目录、凭据和插件数据。需要回退时恢复 v0.1.12 动态库；本次没有删除已有凭据、禁用规则或模型价格。
