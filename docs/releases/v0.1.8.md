## v0.1.8

补齐 Claude Code 原生请求的功能标志和错误详情，支持本地 token 估算，并修复额度周期切换后仍显示旧数据的问题。

### 🛠️ 请求兼容与错误信息

- 保持 Factory CLI 的默认身份和协议版本，根据请求体中的思考展示、上下文管理、工具搜索及中途系统消息等功能追加受信任 beta 标志；调用者 Header 和 SDK `betas` 字段不直接透传。
- HTTP 错误保留上游原始内容，不脱敏、不替换具体错误原因。错误正文读取上限为 32 KiB，错误响应流最多等待 2 秒，随后关闭当前请求。
- 支持 `/v1/messages/count_tokens`，沿用 CPA 第三方 Claude 网关的 O200k 本地文本估算方式，明确标注估算结果，不发起付费推理。
- 尚未实现的跨模型 fallback 明确返回不支持，避免静默提交缺少配套能力的请求。

### 🎨 额度界面

- 官方已知周期结束后隐藏旧周期用量，并在满足 3 分钟间隔后补一次新周期查询；同一周期失败或数据未变化时不反复重试。
- 新周期时间以官方响应为准，悬停重置时间可查看完整日期；不人为推移旧时间或将旧周期消耗算入新周期。
- 消耗使用蓝色图标，预测使用紫色图标，金额与 Token 按 Manager 原生主次文字颜色显示。
- “标准月额度”统一显示为“月额度”，统计范围仍为 Standard 额度池；旧快照名称自动迁移，保留刷新间隔。

### 🧪 验证与构建

- 25 项 Rust 测试，114 项实际 CPA v8.0.52 宿主及前端模块检查。
- 严格模拟上游覆盖完整工具历史、功能标志、原始错误、分段和停滞的错误响应、计数鉴权、周期边界与名称迁移。
- 浏览器验证了蓝紫图标、月额度标签、周期切换后的新用量及重复页面更新不增加查询。
- Windows 打包增加已验证临时目录的短暂占用重试；发布流程要求 Windows x64、Linux x64、macOS Intel、macOS Apple Silicon 全部通过后才公开安装包和 `latest.json`。

### 📦 升级与边界

更新至 v0.1.8 后确认 CPA 已重新加载插件，必要时重启 CPA；刷新管理页面以加载新版界面脚本。原先的账号、凭据和统一价格统计方式保持不变。

Claude 错误响应仍受 CPA 外壳格式约束，但源错误类型和消息原文会保留。CPA 自己仍对 Responses 流式错误做脱敏及限长，本插件不修改该宿主行为。

token 计数为文本估算，不包含图片、音视频及加密内容的精确消耗，不能用于结算。模拟验证不代表所有真实 Factory 功能均已验收；此前同事的原始失败请求仍需更新后复测。
