# 原生凭证模式验收

日期：2026-11-03。CPA v8.0.52，CPA-Manager-Plus v1.14.10 加本仓库的通用插件额度补丁。

## 实际变化

- 插件页面仅保留名称、Factory Key、添加凭证与跳转 CPA 凭证管理。
- 添加凭证自动读取官方目录，不需要逐个添加、选择或付费验证。
- 对外只注册 `factory/<模型>`，取消账号 UUID 对应的重复模型 ID。
- 关闭插件独立记账能力；CPA 的原生用量通道供 Manager 采集和统计。
- Manager 卡片及抽屉按宿主声明的插件能力提供额度刷新。

## 范围限制

目录中出现模型表示原生路由已注册，实际调用权限和额度仍由 Factory 返回。
当前只发布已支持的 Messages、Responses、Chat Completions 路由；Google、自定义和路由型模型不冒充可用。
Manager 只从现在的原生请求采集历史，插件旧账本不会自动导入。
通用额度接口没有完整的模型池范围信息，因此 Manager 不用整账号请求量推算每个池的消费。
Manager 补丁为本地适配，尚未提交到上游或发布新的插件版本。
