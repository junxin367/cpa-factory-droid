使用帮助

从连接账号开始，了解每项数据的来源和边界。

Factory Droid
01

安装与管理授权

在 CPA 插件管理中安装并启用 Factory Droid，再从插件菜单打开本页面。静态页面可直接打开，管理接口仍由管理器鉴权保护。

同源部署时优先复用管理器已保存的会话；未保存或无法复用时，点击“管理授权”输入当前管理器密钥。直连 CPA 使用 CPA 管理 Key；CPAMP Full Mode 使用当前 Admin Key。

本插件不会另行保存密钥。不要在管理授权中输入 Factory API Key；Factory 凭据只在“添加账号”时填写。

02

连接账号与选择允许模型

在添加弹窗填写名称与 Factory API Key，获取候选后多选模型，设置本账号的调用别名，再按需测试。创建前凭据仅保留在有时效的服务端内存草稿，关闭弹窗会清除草稿。

可先以零模型或待验证模型创建账号查看额度；只有基础验证有效的模型才会发布。测试每个模型发送一次固定短请求，最多 128 输出 Token，会消耗额度；只证明该次基础调用成功，不证明工具、图像等全部能力。

本账号别名只改变固定账号模型 ID。所有模型价格在“模型与价格”中统一维护，账号不再单独覆盖价格。

03

官方额度、FSC 与本地估算

官方额度：Factory Billing Limits 返回的实际额度窗口、剩余百分比与重置时间；仅展示接口已提供的窗口。无权限或查询失败时说明原因，不补造余额。

官方消耗：Factory Analytics 返回的已使用 FSC，按实际周期展示。它与本地加权 token 不是同一个单位。

本地估算：根据插件收到的 token usage 与模型倍率计算。美元费用仅在配置了对应单价且数据足够时显示，不能作为官方账单。

04

统计、预算与候选目录

历史用量：业务调用和基础验证分别记录；可按请求类型筛选。全局预算包含两者的消耗，失败验证也会记录，缺少上游 usage 时不会补造 token。

候选目录：官方 CLI 只提供候选，读取成功或显示候选数量不代表账号有模型权限。目录过期、读取失败及明确禁用项会单独标记；没有明确路由的候选不会自动加入模型定义。

模型路由：不配置 droid-cli-path 仍可对已配置原生路由手工基础验证。固定账号模型是可选路由，只列出实际生效并发布的模型，其原生协议与共享模型相同。

按模型配置的原生协议调用

每个模型只支持其显式配置的 protocol。以模型页面显示的协议和端点为准，不能通过模型名称判断，也不能换用其他协议端点。

原生协议protocol 配置值唯一支持的调用端点
Anthropic 消息协议anthropicPOST /v1/messages
OpenAI Responses 响应协议responsesPOST /v1/responses
OpenAI 聊天补全协议chat_completionsPOST /v1/chat/completions

调用方式与配置不匹配时返回 400 protocol_mismatch，请求不会转发到 Factory。点击模型旁的“调用示例”可复制匹配的请求模板，再替换为你的 CPA 推理地址和 CPA 客户端 API Key。

连接异常时如何检查

管理授权失败：直连 CPA 时填写 CPA 管理 Key，CPAMP Full Mode 时填写当前 Admin Key，并确认宿主允许当前来源访问管理端。

接口不存在：确认 Factory Droid 已成功加载，且宿主支持插件管理 API 与静态资源菜单。

账号验证失败：检查 Factory API Key 是否有效。官方用量显示“不可读取”时，先查看具体原因，不要将其视为余额不足。

刚修改启停或模型配置：刷新页面数据确认 CPA 返回的实际注册状态；模型目录本身不保证上游账号拥有权限。
